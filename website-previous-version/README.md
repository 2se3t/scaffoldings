# YugStroyMontazh — сайт аренды строительных лесов и трапов

Источник дизайна и сведений: `C:\Users\Set\Desktop\scaffolding.co`.
Использованы исходные логотип, фотография, цвета #B01F28 / #FDFDFB, шрифты Onest и Roboto Condensed.
Из MD взяты направления услуг, география и структура запросов. Проценты рынка, цены, стаж, объём парка, сертификаты и обещания сроков не подтверждены и на сайт не перенесены.

## Запуск

Нужен только Node.js, внешних npm-зависимостей нет.

```powershell
npm run build
npm run check
npm run dev
```

Открыть `http://127.0.0.1:4173/`. Публикуемая статическая папка: `dist`.

## Контакты и публикация

Править `site.config.json`:

- `phone`: настоящий отображаемый телефон, например в международном формате; сейчас null.
- `whatsapp`: рабочий номер WhatsApp с кодом страны; сейчас null. Сайт убирает форматирование из wa.me.
- `address`: подтверждённый адрес выдачи, сейчас null.
- `mapUrl`: ссылка на реальную карточку компании, сейчас null.
- `origin`: итоговый HTTPS-домен без завершающего слеша. Сейчас URL закрытого предпросмотра Sites.
- `publicLaunch`: сейчас false: robots запрещает обход, все страницы noindex. Переключать только при готовности к публичному запуску и наличии телефона / WhatsApp. `npm run check` проверит это.

Поля тарифов зарезервированы, но не участвуют в расчёте: без подтверждённых правил тарификации сайт показывает «По запросу». Калькулятор считает площадь фасада или принимает число трапов, срок и способ получения. Количество секций, анкеров и допустимую нагрузку не рассчитывает.

При отсутствии номера калькулятор честно предлагает скопировать/скачать запрос и сообщает, что отправка недоступна. После заполнения `whatsapp` и пересборки появляется ссылка в WhatsApp с редактируемым сообщением. Сайт сам ничего не отправляет и не показывает фиктивное «заявка отправлена».

После правок выполнить build и check, затем опубликовать `dist`. Для Sites использовать тот же `project_id` из `.openai/hosting.json`, не создавать второй сайт. Все метаданные, sitemap, hreflang и JSON-LD генерируются из одного origin. После подключения домена пересобрать сайт с новым origin.

## Структура

Русский: `/`, `/arenda-stroitelnyh-lesov/`, `/arenda-trapov/`, `/dostavka/`, `/privacy/`.
Казахский: соответствующие страницы в `/kz/` с HTML lang=kk и hreflang=kk.

Тексты, разметка и генератор: `scripts/build.mjs`. Стили: `assets/styles.css`. Калькулятор и меню: `assets/app.js`.

Локальные шрифты: Onest / Roboto Condensed из Google Fonts, SIL Open Font License (см. `assets/FONT-LICENSES.md`). Фотография сжата до адаптивных WebP; оригиналы остаются нетронутыми в папке материалов.
